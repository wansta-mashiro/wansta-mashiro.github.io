プライバシーポリシー

制定日: 2026年11月11日

1. このページについて

YouTube チャンネル「わんスタ☆【ましろ先生の中学1問1答】」の運営者（以下「運営者」）が、チャンネルの運営のために使っている動画管理ツール（以下「本ツール」）での、情報の取り扱いを説明するページです。

2. 本ツールを使う人

本ツールを使うのは運営者本人だけです。一般の方に配布・提供していません。視聴者のみなさんが本ツールにログインしたり、情報を入力したりすることはありません。

3. 本ツールが扱う情報

本ツールは YouTube API サービスを利用し、運営者自身の Google アカウントの許可のもとで、運営者自身のチャンネルについて次のことを行います。

  • 動画の投稿、タイトル・説明文・サムネイル・再生リスト・公開設定の管理
  • チャンネルと動画の統計情報（視聴回数、再生時間、登録者数など）の取得

取得する統計情報は集計された数字で、視聴者個人を特定できる情報は含みません。本ツールが運営者以外の方の個人情報を集めることはありません。

4. 情報の保管と共有

  • Google アカウントの許可情報は、運営者が管理する環境にだけ保管し、公開しません。
  • 取得した情報は、チャンネルの運営と改善のためだけに使います。
  • 第三者への販売・提供は行いません。

5. 許可の取り消し

運営者は、Google アカウントのセキュリティ設定から、本ツールへの許可をいつでも取り消せます。

6. YouTube と Google の規約

本ツールは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約が、Google による情報の取り扱いには Google プライバシーポリシーが適用されます。

7. お問い合わせ

YouTube チャンネルの概要欄に記載の連絡先までお願いします。

8. 変更について

内容を変更したときは、このページでお知らせします。
